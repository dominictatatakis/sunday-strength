How to use it 
curl -H "Authorization: Bearer YOUR_KEY" \
  {{ request.base_url }}api/v1/plan

# tick an exercise off, with the load you used: 3 sets of 8 at 60kg.
# reps are per set, and weight is per dumbbell — not the pair.
curl -X POST {{ request.base_url }}api/v1/completions \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"day": 1, "slug": "bench-press", "sets": 3, "reps": 8, "weight_kg": 60}'

# everything you've logged, newest first
curl -H "Authorization: Bearer YOUR_KEY" \
  {{ request.base_url }}api/v1/completions?limit=50

Also available: /api/v1/me. Add ?week=2026-W30 to /api/v1/plan for any other week.
